THINKSPRINT– Interactive Programming Quiz App

Thinksprint is an interactive quiz application designed to help learners practice programming concepts and test their knowledge.

Live Demo

"Play Thinksprint" (https://kallem-anjali.github.io/THINKSPRINT/)

Features

- Interactive quiz interface
- Questions loaded using a JavaScript API request
- Answer selection and quiz navigation
- Responsive design (if supported by the current implementation)

Technologies Used

- HTML5
- CSS
- JavaScript
- API integration

Project Structure

- "index.html" – Application structure
- "style.css" – Styling and layout
- "script.js" – Quiz logic and API integration

How to Run Locally

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Start using the quiz.

Future Improvements

- Programming category selection
- Timer and progress indicator
- Score summary and results page
- Improved mobile experience
